# فيتشر الإعدادات والملف الشخصي (`settings&`)

دليل الملفات — كل سطر: **أيقونة** + **المسار** + **الوظيفة**.

## 📁 الهيكلة

| أيقونة | الملف | المطلوب / الوظيفة |
|:------:|------|-------------------|
| 🏷️ | `profile_labels.dart` | ترجمة عرض الجنس، الحالة، اللغة (عربي / English قريباً) |
| 📦 | `models/user_profile.dart` | نموذج بيانات المستخدم (اسم، بريد، إجابات التهيئة، دواء) |
| 🔄 | `providers/profile_provider.dart` | حالة الشاشة + Firebase (تحميل، حفظ، خروج، ثيم داكن) |

### `ui/widgets/` — ويدجت مشتركة

| أيقونة | الملف | المطلوب / الوظيفة |
|:------:|------|-------------------|
| 🧩 | `settings_ui.dart` | بطاقات، عناوين، صفوف تنقل، أزرار، تبديل لغة |
| 💊 | `medication_card.dart` | بطاقة عرض دواء واحد في القائمة |

### `ui/pages/` — الشاشات

| أيقونة | الملف | المطلوب / الوظيفة |
|:------:|------|-------------------|
| 👤 | `profile_page.dart` | **ملف شخصي** — صورة، اسم، بريد، جوائز |
| ⚙️ | `settings_page.dart` | **إعدادات** — معلومات، دواء، عام، حول التطبيق |
| 💊 | `medication_page.dart` | **قائمة الأدوية** + زر إضافة |
| ➕ | `add_medication_page.dart` | **إضافة دواء** — اسم، أوقات تناول متعددة |
| 📄 | `privacy_policy_page.dart` | **سياسة الخصوصية** — نص السياسة كاملاً |

## 🔀 مسار التطبيق (Flow)

```
🏠 الرئيسية → 👤 profile_page
                    ↓ ⚙️
              ⚙️ settings_page
                    ↓ 💊 (إدارة الأدوية)
              💊 medication_page
                    ↓ ➕
              ➕ add_medication_page
```

## 🔗 اعتماديات خارجية

| أيقونة | المكان | الربط |
|:------:|--------|------|
| 🔥 | `UserService` | `lib/core/services/user_service.dart` |
| 🎨 | `AppColors` | `lib/core/theme/app_colors.dart` |
| 🏠 | فتح الملف الشخصي | `home_page.dart` → أيقونة الشخص |
